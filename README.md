# Fischer's Quest

Fischer's-フィッシャーズ- の2016年以降の動画を選び、選択順に視聴する単体HTMLアプリです。

## 視聴の流れ

期間・検索・視聴状態に合う未選択の動画から、ランダムに5本ずつ候補を表示します。1本選ぶたびに視聴リストへ追加し、次の5本に入れ替えます。まだ表示していない動画を優先し、候補が5本未満の場合は残っている本数だけ表示します。入れ替えアイコンで候補だけを引き直すこともできます。

動画を選ぶと、合計時間と現在時刻からの終了予定を表示します。開始前は順番の変更と削除ができます。動画時間の取得にはYouTube Data APIキーが必要です。広告・一時停止・通信待ちは終了予定に含みません。

クエスト開始後は選択内容を固定し、最後まで再生した動画から順番に次へ進みます。サイト内に関連動画一覧やスキップボタンはありません。早送りで未視聴部分を飛ばした場合は、保存済みの視聴位置へ戻します。YouTube内の関連動画表示そのものを完全に無効化することはできません。

全動画が終わるとプレイヤーを破棄して黒いロック画面になり、30分後に選択画面へ戻ります。進捗とロック終了時刻は同じブラウザに保存され、再読み込み後も引き継ぎます。ブラウザ保存データの削除・端末時計の変更・別ブラウザの利用まで防ぐ強制ロックではありません。

スマホ等で自動再生が制限されたときは「再生を再開」を押してください。埋め込み禁止・削除等のエラーでは次の動画へ飛ばず、同じ動画の再読み込みを表示します。

## GitHub Pages

GitHub Pagesではリポジトリ直下の `index.html` を公開してください。

このフォルダの `index.html` と `outputs/github-pages-site/index.html` は同じ内容です。外部のローカルJSファイルを追加せず、`index.html`単体をアップロードできます。YouTubeプレイヤーの利用にはネット接続が必要です。

スマホでは公開URLをSafariまたはChromeで開き、ホーム画面に追加するとアプリ風に使えます。

## APIキー

YouTube Data APIキーはブラウザの `localStorage` に保存されます。リポジトリにはAPIキーを保存しないでください。

## 検証

`node tests/quest.test.cjs` で選択・時間取得・日付をまたぐ終了予定・順番固定・スキップ判定・ロック永続化と解除を検証します。

`node tests/candidates.test.cjs` で5本抽選・期間と検索条件・選択済み除外・候補の安定性・候補切れを検証します。

`tests/quest.browser.js` はPlaywright CLIの `run-code --filename` 用です。ローカルの `http://127.0.0.1:8876` でHTMLを配信して実行します。テスト用APIと模擬プレイヤーを使用し、実際のAPIキーやYouTube動画は消費しません。
